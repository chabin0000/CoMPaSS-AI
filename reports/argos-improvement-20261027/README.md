## 검수와 해석의 한계

실제 사람 검수자는 **0명**입니다. R6 실험은 Codex 단일 AI의 비블라인드 판정이며 새 후보 문서 응답 288개의 설명을 검수했습니다. 기본 모델의 동일한 96개 문서 출력은 기존 판정을 재사용했습니다. R6 실험 중 웹 ChatGPT 협의는 진행하지 않았습니다. 이후 사용자가 다시 요청한 최종보고서의 역사 조사에서 기존 웹 프로젝트 Pro와 두 차례 대조했으며, 이는 R6 문항 재채점이나 독립 사람 검수가 아닙니다. [대조 내용과 한계](public-data/synthesis_peer_review.json)를 공개합니다.

기존 연구의 주장 단위 798개 분석과 72쌍·두 AI의 144개 최초 선호 판정은 보존했습니다. R6 전체 주장 단위 재집계, 별도 자연스러움·쌍대평가, 사람 간 일치도, 두 번째 학습 seed, 새 독립 최종 추론은 수행하지 않았습니다. 학습 손실 감소를 능력 향상으로 해석하지 않으며 부정적 결과도 그대로 보고합니다.

기존 정치·역사 40문항에서는 S5 일반 모델이 37개, 두 교사가 31개·36개였으며, 제공 자료 124문항에서도 S5 87개가 교사 59개·80개보다 높았습니다. 이 관측을 보고서에 보존했습니다. 선정에 사용된 자료이고 여러 하위집합을 비교했으므로 특정 분야의 일반적 교사 초월을 확증한 결과로 해석하지 않습니다.

## 공개 자료로 재계산

이 폴더에서 Python 3으로 실행합니다. 외부 패키지·GPU·인증 정보가 필요하지 않습니다.

```shell
python code/recompute_public_report.py
python recovery-code/recompute_round.py
```

첫 명령은 기존 1,760개 비교 응답과 주장·쌍대평가를 검증합니다. 둘째는 이번 704개 개발·224개 진단 응답, 학습 영수증, 해시 연결, 유형별 결과와 모든 선정 조건을 재계산합니다. 두 명령은 저장된 AI 판정의 집계와 무결성을 점검하며 의미적 타당성을 새로 심사하는 독립 검수는 아닙니다. 전체 후속 작업의 표준 응답 수는 3,128 + 928 = 4,056개이며 기존 별도 출력 경로 탐색 8개는 따로 셉니다.

최종 종합 보고서의 표·그림·익명 시간 집계와 PDF를 추가 검증하려면 `pypdf`를 설치한 뒤 아래 명령을 실행합니다.

```shell
python report-code/verify_final_report.py
```

Windows의 맑은 고딕과 `numpy matplotlib Pillow reportlab pypdf`가 있으면 동일 원고에서 그림·PDF·Markdown을 다시 만들 수 있습니다. 생성 PDF의 파일 메타데이터나 SVG 작성 시각은 달라질 수 있습니다.

```shell
python report-code/create_figures.py --data public-data/report_data.json --out figures
python report-code/render_pdf.py --data public-data/report_data.json --figures figures --output ARGOS_Improvement_Report_KO.pdf
python report-code/export_markdown.py --data public-data/report_data.json --output REPORT_KO.md
```

HTML은 같은 원고·표와 핵심 비교의 편집 가능한 차트를 사용합니다. 18개 출판용 그림은 PDF·Markdown과 `figures/`에 제공하며, HTML 안에 18개 이미지를 모두 중복 삽입하지 않았습니다. `report-code/authored-ui/`에는 사용자 영역의 React·CSS만 포함했습니다. HTML 재빌드는 Codex Data 플러그인 런타임이 필요하며, 공개 오프라인 HTML 자체는 별도 서버 없이 열 수 있습니다.

`public-data/validation_receipt.json`은 현재 39쪽 보고서의 검증 기록입니다. 이전 23쪽 기록은 `prior_validation_receipt.json`, 34쪽 기록은 `pre_synthesis_validation_receipt.json`에 보존했으며 현재 산출물의 해시로 사용하지 않습니다. `synthesis_input_manifest.json`은 종합 보고서를 작성하기 전의 입력 스냅샷을 기록합니다. `recovery_freeze.json`의 보고서 작성 대기 상태는 모델 선정을 동결하던 시점의 원본 기록입니다. 문서 완성 상태는 최신 검증 기록에서 확인합니다. [MANIFEST.json](MANIFEST.json)은 자기 자신을 제외한 공개 묶음의 경로·크기·SHA-256을 기록합니다.

## 공개 범위

합성 개발 문제·정답 근거·보이는 최종 출력·판정을 공개합니다. 공개 벤치마크 문제 본문은 재배포하지 않고 출처·고정 식별자·정답·모델 출력·채점 결과를 제공합니다. 교사 내부 추론 채널, 원문 학습 지문, 모델 가중치, 계정 인증·실제 잔액·자원 식별자, 개인 프로젝트 URL, 미사용 최종 문항·정답·복원용 생성 코드는 포함하지 않습니다.

실행 소스는 검토용으로 포함했으나 비공개 입력과 가중치가 없으므로 전체 학습을 한 명령으로 재현하는 배포물은 아닙니다. 설정·고정 리비전·해시·공개 집계의 재계산 범위를 구분했습니다. 각 원 모델과 데이터의 이용 조건은 원 출처를 따릅니다.
