# 실험 프로토콜

연구 질문은 동일 학생 모델과 학습 조건에서 독립 검증을 통과한 다중 교사 데이터(S4)가 미검증 다중 교사 데이터(S3)보다 한국어 STEM·사실 검증 성능과 사실성에 유리한지 확인하는 것이다.

- S0: 추가 학습 없는 기반 학생 모델
- S1/S2: 각각 gpt-oss-120b/GLM-4.5-Air 단일 교사 데이터
- S3a: 검증 전 두 교사 후보를 각각 독립 학습 표본으로 유지한 데이터
- S3b: 답의 품질을 보지 않고, 정렬된 question_id의 교대 규칙으로 질문당 교사 답 1개를 선택한 데이터
- S4: 독립 검증을 통과한 질문당 최종 답 1개 데이터. `S4_teacher_only`와 `S4_with_human_correction`을 별도 보고한다.
- S5: S4와 검증 가능한 한국어 원천 데이터를 결합하는 확장 조건

주실험 비교는 **S3_matched vs S4_teacher_only**다. 두 조건은 동일 question_id, 표본 수, 영역 분포를 자동 검증한다. S3_matched는 S4_teacher_only의 ID 집합으로 범위를 제한하지만, 각 질문의 교사 선택에는 검증 결과·정답·품질을 사용하지 않는다. S3a는 데이터량 증가 보조 조건, S4_with_human_correction은 실용적 고품질 데이터 보조 조건, S5는 향후 한국어 원천 데이터 확장 조건이다.

현재 범위는 Mock 교사 A/B, 정답표 기반 검증, JSONL 계약, 누출 차단, 실행 로그 검증이다. S5는 검증된 한국어 원천 데이터가 입력되기 전에는 `placeholder`/`not_executed` 상태이며 S4 복사 조건으로 해석하지 않는다. Mock 결과는 소프트웨어 파이프라인 구현 검증이며 실제 AI 모델 성능 결과가 아니다.

실제 실험에서는 학습 전 비공개 최종 평가셋을 따로 제작하고, 학습·파일럿·평가 ID 및 문자 중복을 검사한다. S3a/S3b/S4의 질문 ID coverage·표본 수·교사 구성·영역 분포·문자 수·근사 토큰 수·평균 답 길이와 S4의 human_corrected 비율을 보고하며, 토크나이저가 다르면 근사값을 실제 토큰 수로 해석하지 않는다.
