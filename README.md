# CoMPaSS-AI · ARGOS

서로 다른 교사 언어모델의 답변을 검증하고 EXAONE 학생 모델에 학습시킨 연구입니다. **실제 본실험은 임대한 RTX A5000 24GB에서 진행했습니다.** DGX Spark는 초기 구상에 해당하며, 초기 교사 수집의 실제 장비는 보존된 메타데이터만으로 독립 확인할 수 없습니다.

[기존 제작 연구의 별도 보고서](reports/argos-final-20261027/REPORT_KO.md) · [기존 PDF](reports/argos-final-20261027/CoMPaSS_ARGOS_final_report_20261027.pdf) · [기존 집계와 근거](reports/argos-final-20261027/data/)

후속 실험에서는 대여 A5000 24GB에서 기본 모델과 두 교사의 기준선을 측정하고 세 학습 조건의 여섯 저장본을 평가했습니다. 이후 사용자가 선택한 마지막 한 차례의 학습 R6(120단계)를 수행해 40·80·120단계 저장본을 모두 평가하고 연구를 동결했습니다. R6-120은 같은 개발셋에서 기존 ARGOS의 문서 35/96·수학 6/40을 55/96·34/40으로 회복했습니다. 이전 후보 B4-075보다 문서·수학이 각각 2개 늘었지만 KoBEST 공식 정답은 1개 줄었고, 기본 모델 68/96·35/40에는 미달했습니다. **두 교사 초월은 입증하지 못했습니다.**

고정 선정 기준을 통과한 후보가 없어 새 봉인 최종시험은 실행하지 않았습니다. 새 합성 문서 200개와 이전 미추론 공개 최종 80개는 보존했습니다. 이번 차수의 계정 차감은 약 $0.46, 최초 $10 예산 관측부터 누적 차감은 약 $2.22이며 백업 후 GPU 종료를 확인했습니다. 저장소 비용은 이후에도 발생할 수 있습니다. 이번 R6의 검수는 단일 AI이며 사람 검수는 0명입니다. R6 실험 중 웹 ChatGPT 협의는 하지 않았으며, 이후 사용자 요청으로 최종보고서의 역사·해석을 기존 프로젝트 Pro와 두 차례 대조했습니다. 아래 기존 동결 평가와 이번 개발 결과는 문서 구성·실행 환경·목적이 다르며 공개 유지 부분집합은 재사용했습니다.

전체 지출 $40과 PC 가동 96시간은 사용자 보고입니다. 확인된 설계 시작부터 동결까지 79일이 지났으며, 프로젝트 로그에서 자동 기록을 제외한 메시지 177개의 연결 구간은 30분 규칙으로 13.92시간입니다. **이 수치는 직접 작업 시간이 아닙니다.** 실제 투입 시간은 기록만으로 확정할 수 없으며 [계산 방법과 한계](reports/argos-improvement-20261027/public-data/synthesis_activity.json)를 공개합니다.

## 무엇을 만들었나

학생 기반 모델은 EXAONE-3.5-7.8B-Instruct이며, 10월 본실험의 교사는 gpt-oss-20B와 GLM-4.7-Flash입니다. 같은 기반 모델에서 학습 조건별로 독립 어댑터 10개를 만들었습니다. 열 단계를 연속 학습하거나 열 모델을 합친 구조가 아닙니다. 기존 제작 연구의 동결 대상은 `S5_general_control-20261022`이며 후속 개선 연구에서 이를 대체할 승격 후보는 확보하지 못했습니다.

8월 초기 Pilot의 신규 20문항 정답은 기반 8개에서 Pilot 12개로 증가했습니다. 보존된 당시 도구 출력에서 복원한 소규모 결과이며, 정확 McNemar 검정은 p=0.125입니다. 10월 최종 모델의 성과와 합산하지 않습니다.

## 기존 동결 평가 결과

**최종 ARGOS는 제공 자료 충실성과 공백 정규화 후 전체 응답 일치율이 높아졌지만 수학 능력이 크게 저하됐습니다. 전반적인 성능 향상이나 교사 모델 초과는 확인하지 못했습니다.**

| 새 동결 평가 | 기반 EXAONE S0 | 최종 ARGOS |
| --- | --- | --- |
| 수학 내용 정답 | 68/80 | 37/80 |
| 제공 자료의 요청 사실 충족 | 53/60 | 60/60 |
| 전제 판단의 결론 정답 | 55/60 | 50/60 |
| 공백 정규화 후 전체 응답 일치 | 3/40 | 27/40 |
| KLUE NLI 표본 | 33/40 | 36/40 |
| KoBEST BoolQ 표본 | 36/40 | 37/40 |
| GSM8K 표본 | 37/40 | 6/40 |

각 행의 과제와 채점 기준이 다르므로 하나의 종합 지능 점수로 합치지 않습니다. 공개 벤치마크는 각각 40문항의 보조 표본이며 공식 전체 벤치마크 결과가 아닙니다.

교사와 함께 실행한 **기존 확장 240문항**에서는 내용·지시 동시 통과가 ARGOS 96개, gpt-oss-20B 177개, GLM-4.7-Flash 206개였습니다. 이 기존 평가는 모델 선정에도 사용했습니다. 교사들은 새 240문항에 재평가하지 않았으므로 새 시험에서의 교사 대비 우열을 주장하지 않습니다.

기록으로 확인되는 독립적인 사람 검수 완료 인원은 0명입니다. 응답 판정은 단일 AI로 수행했으며, 사람 2명 검수와 독립 평가자 일치도를 완료했다고 표기하지 않습니다. 보고서는 기존 ChatGPT 프로젝트 대화에서 Pro → xhigh → Pro로 세 차례 의견을 주고받으며 수정했습니다. [합의 과정](reports/argos-final-20261027/AI_REVIEW_CONSENSUS_KO.md)은 문항별 독립 이중 채점과 구분합니다.
