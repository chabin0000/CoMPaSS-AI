## 재계산

이 폴더에서 Python 3으로 실행합니다. 외부 패키지·GPU·인증 정보가 필요하지 않습니다.

```shell
python code/recompute_public_report.py
```

합성 개발960응답과 공개 유지800응답의 저장 판정, 주장120응답, 쌍대72개·AI 판정144개에서 표와 지표를 재계산합니다. 정답·근거의 의미를 새로 판정하는 독립 검수는 아닙니다. `public-data/validation_receipt.json`에 실제 실행 및 PDF 검수 범위를 기록했습니다.

## 공개 범위

합성 개발 문제·정답 근거·최종 출력·판정을 공개합니다. 공개 벤치마크 문제 본문은 재배포하지 않고 출처와 고정 식별자·정답·모델 출력·채점 결과를 제공합니다. 내부 추론 채널, 원문 학습 지문, 모델 가중치, 계정 인증·잔액·자원 식별자, 개인 프로젝트 URL 및 미사용 최종 문항·정답·복원용 생성 코드는 포함하지 않습니다.

설정·리비전·해시는 공개하지만 공개 묶음만으로 학습부터 완전히 재실행할 수 있다는 뜻은 아닙니다. 각 원 모델·데이터의 이용 조건은 원 출처를 따릅니다. [이전 ARGOS 보고서](../argos-final-20261027/REPORT_KO.md)는 별도로 보존했습니다.
