# 설계 결정 기록

## 2026-08-09: S3/S4의 표본 단위 통제

1. 기존 계획: S3에는 같은 질문의 두 교사 후보를 독립 후보로 보관하고, S4에는 검증·수정한 최종 답 1개를 사용한다.
2. 발견한 문제: S3에 두 후보를 모두 학습 표본으로 넣고 S4에 하나만 넣으면 표본 수·교사 비율·총 문자량이 함께 바뀌어 검증 효과와 데이터 양 효과를 분리하기 어렵다.
3. 수정한 설계: 원본 후보는 모두 보존한다. 조건 빌드에서는 S3를 질문당 1개 후보로 A/B 교대 선택하고, S4는 질문당 검증 통과 최종 답 1개를 선택한다. 집합 차이와 통제값은 반드시 요약한다.
4. 수정 이유: 다중 교사 여부와 독립 검증 여부를 비교할 때 표본 단위를 질문으로 통일해 교란을 줄이기 위해서다.
5. 결과 해석 영향: S4가 검증 실패 문항을 제외해 S3와 질문 집합이 달라질 수 있으므로, 결과는 통제 통계와 함께 해석하며 단순 인과 주장으로 과장하지 않는다.

## 2026-08-09: S3a와 S3b를 동시에 보존

1. 기존 계획: S3을 검증 없는 다중 교사 데이터라는 하나의 조건으로만 표기했다.
2. 문제점: 두 교사 응답을 모두 쓰는지, 질문당 하나를 쓰는지에 따라 데이터량과 정보량이 달라져 같은 S3이라는 이름으로 비교하면 해석이 모호하다.
3. 수정안: S3a는 두 교사 응답을 독립 표본으로 보존하고, S3b는 답의 품질·검증 결과를 보지 않는 `alternating_sorted_question_id_no_quality_signal` 규칙으로 가능한 50:50에 가깝게 하나를 선택한다. 둘 다 teacher composition과 selection 결과를 기록한다.
4. 이유: S3a는 다중 교사 정보량을 온전히 측정할 수 있고, S3b는 S4와 질문당 표본 수를 맞추기 쉽다.
5. 결과 해석 영향: S3a 대 S4는 데이터량 차이가 교란변수일 수 있다. S3b 대 S4는 데이터량 통제에는 유리하지만 다중 교사 정보를 완전히 사용한 조건은 아니다. 본실험 주조건은 아직 정하지 않는다.

## 2026-08-09: 사람 보정 효과의 분리

1. 기존 계획: 두 교사가 모두 틀린 경우 human_corrected를 최종 학습 답으로 사용할 수 있었다.
2. 문제점: 사람이 새 답을 작성하면 독립 검증 효과와 사람의 추가 지식 효과가 섞인다.
3. 수정안: `verification_outcome`으로 teacher_a_selected, teacher_b_selected, both_agree_verified, human_corrected, excluded를 기록한다. S4_teacher_only와 S4_with_human_correction을 분리하고 human_corrected 비율을 자동 요약한다.
4. 이유: 교사 답의 검증·선택 효과와 사람 보정 효과를 별도 분석하기 위해서다.
5. 결과 해석 영향: human_corrected 비율이 높은 S4 향상은 순수한 교사 통합 효과로 해석하지 않는다.

## 2026-08-09: S5 placeholder 명시

1. 기존 계획: S5는 S4와 검증 가능한 한국어 원천 데이터를 결합하는 조건이다.
2. 문제점: 한국어 원천 데이터가 없는데 S4를 S5로 복사하면 S5가 실제 실험된 것처럼 보일 수 있다.
3. 수정안: 원천 데이터가 없으면 S5 JSONL은 빈 상태이고 summary metadata에 `placeholder`를 기록한다.
4. 이유: 존재하지 않는 한국어 데이터 효과를 생성하지 않기 위해서다.
5. 결과 해석 영향: 현재 S5에는 결과가 없으며 S4와 비교하거나 성능을 주장할 수 없다.

## 2026-08-09: 주실험을 matched comparison으로 고정

1. 기존 계획: S3과 S4를 비교하되, S3a/S3b와 S4의 ID·표본 수 차이를 하나의 조건 비교 안에서 완전히 제거하지 못했다.
2. 문제점: S3a 대 S4는 데이터량 차이가 섞이고, 전체 S3b 대 S4_teacher_only는 question_id와 표본 수가 다르며, S3b 대 S4_with_human_correction은 사람 보정이라는 추가 학습 신호가 섞인다.
3. 수정안: S4_teacher_only의 question_id 집합만을 범위로 한 S3_matched를 생성한다. 각 질문에서 원래 교사 응답 하나를 검증 결과·정답·품질을 보지 않는 결정론적 균형 규칙으로 선택하고, ID 집합·표본 수·영역 분포 일치 검사를 통과할 때만 paired comparison을 만든다.
4. 이유: 같은 질문에서 blind selection과 verification selection을 비교해야 독립 검증 효과에 가장 가깝기 때문이다.
5. 결과 해석 영향: S3_matched vs S4_teacher_only를 주실험 비교로 해석한다. S3a는 데이터량 증가 보조 조건, S4_with_human_correction은 사람 수정이 포함된 실용적 고품질 보조 조건, S5는 향후 한국어 원천 데이터 조건으로만 해석한다.
