## 마지막 실험에서 한 일

- 같은 기본 모델에서 기존 어댑터 강도만 바꾼 224응답으로 문서 성능 저하를 확인했습니다. 어느 학습 요소가 원인인지를 단독으로 분리한 실험은 아닙니다.
- 상세 계산 풀이 600개, GSM8K 공식 train 240개, 기존 SQuAD train 근거 예제 120개로 총 960개·감독 토큰 98,092개를 구성했습니다.
- 고정 EXAONE 리비전의 NF4·LoRA로 한 번 학습하고 40·80·120단계 저장본을 모두 평가했습니다. 기본 모델과 후보들의 개발 응답은 704개이며 진단까지 이번 차수 총 928응답입니다.
- 문서 73/96, 수학 35/40, 유효 설명 42/96, KoBEST 공식 36/40·오류수정 37/40이라는 고정 하한을 모두 통과한 후보는 0개였습니다. 추가 학습·재선정은 종료했습니다.
- 새 합성 문서 200개와 이전에 추론하지 않은 공개 최종 80개를 학습 전에 로컬 해시로 봉인했습니다. 통과 후보가 없어 최종 추론은 0건이며 결과는 미측정입니다. 외부 타임스탬프 인증이나 280개 전부 신규 비공개 문항이라는 뜻은 아닙니다.
- 가중치·응답·판정의 백업을 검증하고 **2026-10-27 15:01:20 KST에 GPU 종료 상태를 확인**했습니다. 이번 차수 계정 차감은 약 **$0.46**, 최초 $10 예산 관측부터 누적 차감은 약 **$2.22**입니다. 준비·평가·백업·기존 저장소 비용을 포함할 수 있는 계정 차액이며 순수 학습 요금이 아닙니다. 중지된 저장소 보관료는 이후에도 발생할 수 있습니다.

## 검수와 해석의 한계

실제 사람 검수자는 **0명**입니다. 이번 차수는 Codex 단일 AI의 비블라인드 판정이며 새 후보 문서 응답 288개의 설명을 검수했습니다. 기본 모델의 동일한 96개 문서 출력은 기존 판정을 재사용했습니다. 웹 ChatGPT와의 협의는 사용자의 중단 요청 이후 이번 차수에 진행하지 않았습니다.

기존 연구의 주장 단위 798개 분석과 72쌍·두 AI의 144개 최초 선호 판정은 보존했습니다. R6 전체 주장 단위 재집계, 별도 자연스러움·쌍대평가, 사람 간 일치도, 두 번째 학습 seed, 새 독립 최종 추론은 수행하지 않았습니다. 학습 손실 감소를 능력 향상으로 해석하지 않으며 부정적 결과도 그대로 보고합니다.

## 공개 자료로 재계산

이 폴더에서 Python 3으로 실행합니다. 외부 패키지·GPU·인증 정보가 필요하지 않습니다.

```shell
python code/recompute_public_report.py
python recovery-code/recompute_round.py
```

첫 명령은 기존 1,760개 비교 응답과 주장·쌍대평가를 검증합니다. 둘째는 이번 704개 개발·224개 진단 응답, 학습 영수증, 해시 연결, 유형별 결과와 모든 선정 조건을 재계산합니다. 두 명령은 저장된 AI 판정의 집계와 무결성을 점검하며 의미적 타당성을 새로 심사하는 독립 검수는 아닙니다. 전체 후속 작업의 표준 응답 수는 3,128 + 928 = 4,056개이며 기존 별도 출력 경로 탐색 8개는 따로 셉니다.

`public-data/validation_receipt.json`은 현재 34쪽 보고서의 검증 기록입니다. `prior_validation_receipt.json`은 이전 23쪽 버전의 당시 기록을 보존한 것이며 현재 산출물의 해시로 사용하지 않습니다. `recovery_freeze.json`의 보고서 작성 대기 상태는 모델 선정을 동결하던 시점의 원본 기록입니다. 문서 완성 상태는 최신 검증 기록에서 확인합니다. [MANIFEST.json](MANIFEST.json)은 자기 자신을 제외한 공개 묶음의 경로·크기·SHA-256을 기록합니다.

## 공개 범위

합성 개발 문제·정답 근거·보이는 최종 출력·판정을 공개합니다. 공개 벤치마크 문제 본문은 재배포하지 않고 출처·고정 식별자·정답·모델 출력·채점 결과를 제공합니다. 교사 내부 추론 채널, 원문 학습 지문, 모델 가중치, 계정 인증·실제 잔액·자원 식별자, 개인 프로젝트 URL, 미사용 최종 문항·정답·복원용 생성 코드는 포함하지 않습니다.

실행 소스는 검토용으로 포함했으나 비공개 입력과 가중치가 없으므로 전체 학습을 한 명령으로 재현하는 배포물은 아닙니다. 설정·고정 리비전·해시·공개 집계의 재계산 범위를 구분했습니다. 각 원 모델과 데이터의 이용 조건은 원 출처를 따릅니다.
